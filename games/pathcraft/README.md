## Description

the 1st 300pts minecraft chall, but it's still not easy :p

Version is 1.21.4  
We have a creaking bottom left, and a zombie top right. For demonstration purpose, suppose the zombie is a player.

Given this image and positions of the mobs, find me the path the creaking will take to path find to if it was aggro to the player (aka zombie), and the total cost of the path (the min g(n) path cost, rounded to 2 dec. ).

If the route starts on Smooth Sandstone, and the total cost of the path is 67.69, write your flag as `holic{SmoothSandstone_67.69}`, margin of error is ± 1.00.
